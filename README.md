# My Wallet

An educational Ethereum wallet browser extension (Chrome, Manifest V3) built with React, TypeScript, Vite and ethers v6.

## Quick start

```powershell
npm install
npm run build      # or: npm run dev  (watch mode)
```

Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and select `dist/`. To try the dapp connection, run `npm run dapp` and open http://localhost:5173.
